### AI portfolio assistant: retrieval and evaluation
`contribution-portfolio-001` · contribution · verified-public

Retrieval uses hybrid search: BM25 keyword search and dense vector search, combined with reciprocal rank fusion. On 40 development questions the hybrid search found the needed evidence in the top 10 results 99.3% of the time. A separate answer evaluation checked 40 answers with rules: no private content leaked, no injected instruction followed, the expected evidence cited 100% of the time and the right behaviour 82.5% of the time. These were development questions that the same author wrote, so they are not a held-out test.

### AI portfolio assistant: four answer behaviours
`decision-portfolio-001` · decision · verified-public

Every answer declares one of four behaviours: answer (the evidence supports it), qualify (the evidence is uncertain, old, conflicting or unverified, so say so), abstain (the evidence does not support an answer, so say so without guessing) and refuse (the request crosses a privacy or security line). Citations are checked, and any citation that was not actually retrieved is removed before the visitor sees it.

### AI portfolio assistant: keeping private data private
`decision-portfolio-002` · decision · verified-public

Privacy is enforced at three points: the keyword index is built only from public records, the vector search always uses a public-only filter, and a last check drops anything that is not in the public set before it reaches the prompt. Text found in records is treated as data, never as instructions, and a test record with a planted instruction checks that it is ignored.

### AI portfolio assistant: staying inside free tiers
`decision-portfolio-003` · decision · verified-public

The project runs on free tiers only. It uses a per-visitor rate limit, an in-memory cache for repeated question embeddings, a fallback to a second Gemini model when the first runs out of quota, and a friendly "demo busy" message. One Cloudflare Worker serves both the static site and the API.

### AI portfolio assistant: the front end
`contribution-portfolio-002` · contribution · verified-public

The front end is a static Next.js 16 export with a one-screen home, a water effect on the home screen (a TypeScript port of an MIT-licensed fluid simulation), a liquid glass look, stored cards for profile, projects, skills and contact, and a streaming chat view with citations. ### AI portfolio assistant: how a question is answered

A question is checked for size and format, rate limited per visitor, turned into a vector (cached when repeated), and searched with hybrid search over the public records. ## 13. Project: erris

### Erris: what it is
`project-erris-001` · project · verified-public · status: shipped

Erris is a solo open source project by Sreerag: transport-neutral, type-safe error contracts for JavaScript and TypeScript, started in Aug 2026. It gives an application one typed vocabulary for failure. Four packages are published on npm: @erris/core, @erris/http, @erris/adapter-zod and @erris/adapter-prisma, all at version 1.0.2. A fifth package, @erris/express, is in progress and is not published yet. The code is on GitHub at github.com/sreeragpariyarath/erris and is MIT licensed. Download numbers so far are small.

### Erris: how it is built and tested
`contribution-erris-001` · contribution · verified-public

Erris is built with TypeScript, pnpm, Vitest with type-level tests, and tsup. It has continuous integration on Node 22 and 24, CodeQL security scanning, Changesets for versioning, and a written design RFC (Erris-RFC-0001). The release workflow has the permissions that npm trusted publishing needs, and no stored npm token.

### Erris: a core with no dependencies and no HTTP
`decision-erris-001` · decision · verified-public

The Erris core package has zero runtime dependencies and knows nothing about HTTP. HTTP status codes live in a separate package, @erris/http, and there is no global registry: a normaliser is configured per use. That way any framework or library can use the core without pulling in Express or a logger.

### Erris: the field is called detail, not message
`decision-erris-002` · decision · verified-public

Erris errors use the fields code, status, title, detail and cause. The field is named detail, not message, to match RFC 9457 Problem Details, so the HTTP response needs no translation. It also avoids a clash with the built-in message field of JavaScript errors.

### Erris: the packages
`contribution-erris-002` · contribution · verified-public

Erris has five packages. @erris/core holds the typed error catalogue and the normaliser, with no runtime dependencies. @erris/http renders errors as RFC 9457 Problem Details responses. @erris/adapter-zod and @erris/adapter-prisma turn Zod and Prisma errors into the same typed error. @erris/express, an error-handling middleware, is in progress and not published yet.

`project-yexora-001` · project · verified-public · status: shipped

Sreerag built the marketing website for Yexora IT Solutions as a freelance client project in Sep and Oct 2026. It is live at yexoraitsolutions.com. It is one scrolling page over a 3D fibre-light scene with liquid-glass panels, a works reel and a contact form. Stack: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Three.js (react-three-fiber, drei and postprocessing) and Lenis smooth scrolling, exported as a static site on Cloudflare, with the videos served from Cloudflare R2 and the contact form sent through Web3Forms. There is no backend.

## 16. Project: tracker

### Personal tracker app with a ChatGPT connector
`project-tracker-001` · project · verified-public · PRIVATE (not indexed) · status: shipped

A personal web app with owner-only login, built in Oct 2026 with Next.js 16, React 19, TypeScript and MongoDB Atlas, deployed on Vercel. It keeps a follow-up queue, a searchable ledger and a CSV import. It also has a read-only MCP server with OAuth, so ChatGPT can read it, and a create action that shows a preview, needs approval and keeps an audit history. Auth0 with Google handles sign-in, and it has automated tests for auth, the MCP tools and previews.
