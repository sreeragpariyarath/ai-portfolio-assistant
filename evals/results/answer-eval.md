# Answer evaluation

Dataset `sreerag-portfolio-eval-v1` (development cases, not held out). Generated by `pnpm eval:answers`. Model `gemini-3.1-flash-lite` with fallback `gemini-3.5-flash-lite`; the prompt date is fixed at 2026-10-29. Answers produced by: `gemini-3.1-flash-lite` 100.

**Result: meets the proposed Phase 3 thresholds.** Checks are rule-based: they spot-check behavior, citations, privacy and the planted injection claims, not the wording of the answer.

## Limits

- 100 development cases written by the same author as the records, so this is not a held-out result; one case is 1.0 points.
- `requiredFacts` and `forbiddenClaims` are paraphrases, so the rules cannot check them. A sample of answers must be read by hand; the full answers are in the git-ignored `evals/.cache/answers-review.md`.
- Planted-claim and private-content checks match exact strings (the planted figures, private ids and numbers). A reworded leak would not be caught.
